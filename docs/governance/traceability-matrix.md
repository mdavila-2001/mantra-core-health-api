# Matriz de trazabilidad — negocio, código, API, datos y pruebas

> Documento vivo, iniciado en Fase 1 y actualizado en cada fase posterior del Plan Maestro de
> Documentación. Registra cada afirmación técnica relevante con su evidencia rastreable, y cada
> hallazgo/riesgo con su estado de remediación. No se cierra este documento con filas en blanco o
> ambiguas: cada fila tiene evidencia concreta (archivo, línea, comando o prueba).

## 1. Cómo leer esta matriz

- **ID**: prefijo por área (`ARCH-`, `SEC-`, `DATA-`, `OPS-`, `TEST-`, `GOV-`) + correlativo.
- **Estado**: `ABIERTO` (detectado, sin remediar), `ACEPTADO` (riesgo residual formalmente
  aceptado, con justificación), `REMEDIADO` (corregido, con evidencia de la corrección).
- Toda fila con `Riesgo = CRITICAL` o `BLOCKER` y `Estado = ABIERTO` impide declarar
  `APTO PARA PRODUCCIÓN` en el informe final (Fase 18), salvo que se reclasifique a `ACEPTADO`
  con justificación explícita y aprobación registrada.
