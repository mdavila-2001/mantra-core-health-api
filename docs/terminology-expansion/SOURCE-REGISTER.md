Revisión: 2026-10-05. El registro separa fuentes enlazadas como referencia de contenido que se permite copiar o redistribuir. La licencia de una página no se extiende a materiales de terceros que esa página enlace.

## Atribución y mantenimiento

- MedlinePlus: `Source: MedlinePlus, National Library of Medicine.`; versión del XML `2026-10-03`; se conserva URL de derechos y la fecha de extracción.
- MeSH: atribuir NLM y mantener la versión identificada en cada lote.
- NCI Thesaurus: atribuir NCI y mostrar versión; no implicar aval ni llamar a una adaptación «NCI Thesaurus».
- CDC/NHS/OMS/LOINC/RxNorm: guardar la licencia y versión exacta del artefacto utilizado antes de cada carga, no sólo el enlace a la página general.
- SNOMED CT y materiales de Mayo Clinic no se cargan con el estado de permisos actual.
